### ⭐ Flagship: Emora — AI-Driven Mental Health Support Chatbot

An **agentic AI support platform** offering empathetic conversations, CBT-guided exercises, journaling assistance, mood tracking, and crisis detection.

- 🧠 **13-stage LangGraph workflow** — guardrails, intent & sentiment analysis, memory, RAG retrieval, specialist routing, and response validation
- 📚 **RAG knowledge pipeline** built on Ollama embeddings and ChromaDB
- 🔐 **PostgreSQL persistence** with JWT auth and role-based access for users, counselors, and administrators
